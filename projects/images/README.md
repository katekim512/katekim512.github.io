# 프로젝트 이미지

상세 페이지 HTML과 공통 스타일은 `projects/`에 유지하고, 이미지는 이 폴더 아래 프로젝트별로 관리합니다.

- `child-expedition/`: 아이원정대찾기 — 설문, 서비스 화면, 개선 전후, 성과 자료
- `bbobavoca/`: 뽑아보카 발표 현장
- `kumap/`: KUMAP 발표 현장
- `log-anomaly-detection/`: 로그 이상탐지 발표 현장

상세 페이지에서는 `images/<프로젝트명>/<파일명>`으로 참조합니다.
새 이미지는 공백 없는 설명형 영문 파일명을 사용하고, 원본 비율을 유지합니다.
