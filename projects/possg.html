포쓱 (PoSSG)

AI 기반 개인 맞춤형 취업 로드맵 서비스. 활동 자료를 업로드하면 포트폴리오와 직무를 자동으로 추천해줍니다.

웹 애플리케이션 (1개) 자체 인력 개발 4명

문제 인식

블라인드 채용 확산으로 포트폴리오·자기소개서·면접의 중요성이 커졌지만, 대학생 70명과 대학 취·창업센터 담당자 인터뷰 결과 취업 준비에 대한 막막함이 심각한 수준으로 확인되었습니다. 자체 설문에서도 응답자의 87.1%가 포트폴리오 작성에 어려움을 겪은 경험이 있다고 답했습니다.

특히 저학년 학생들은 어떤 활동을 해야 하는지, 자신의 활동이 어떤 직무에 적합한지조차 판단하기 어려운 정보 공백 상태에 놓여 있습니다. 대학의 취업 지원 프로그램은 존재하지만 대상자와 기간이 제한적이라 이 공백을 채우지 못하고 있습니다.

솔루션

1포트폴리오 자동 생성

활동 자료를 드래그 앤 드롭으로 업로드만 하면 자동 분석을 거쳐 하나의 포트폴리오로 완성됩니다.

2개인 맞춤 활동·공고 추천

개인 데이터를 기반으로, 저학년부터 고학년·취업준비생·이직자까지 시기별로 최적화된 활동과 공고를 추천합니다.

3취업 로드맵 제공

완성된 스펙으로 준비를 돕는 기존 플랫폼과 달리, 스펙을 함께 쌓아가는 과정 자체를 지원합니다.

서비스 플로우

고객(취업준비생·일반 대학생·제휴대학생·이직 준비자)이 희망 직군 정보와 해왔던 활동을 입력하면, 자사가 개인 맞춤형 취업 로드맵과 포트폴리오를 제공합니다. 동시에 학생들의 선호도 및 취업 수치 데이터를 시각화해 제휴대학에 전달하고, 대학은 그 대가로 학생 이용료 일부를 자사에 지급하는 구조입니다.

MVP 개발 완료

대학생 대상 파일럿 테스트와 대학 취·창업 담당자 인터뷰를 통해 pain point를 확인했고, 결제 대행 PG 연동과 서비스 운영 관련 법률 자문도 완료했습니다. MVP 사이트를 서울권 대학 에브리타임 게시판에 게시해 PMF를 확인하는 단계까지 진행했습니다.

경쟁사 대비 차별점

  • 각 대학 서비스·원티드·링커리어 등과 달리, 개인 데이터 기반 맞춤형 활동·공고 추천을 제공합니다.
  • 사용자 작성 없이 자료 업로드만으로 포트폴리오를 자동 생성하는 점이 차별점입니다.
  • 포트폴리오·직무추천·활동분석을 통합한 AI 맞춤 분석 기능을 제공합니다.
  • 저학년부터 적용 가능한 맞춤 로드맵을 제공하고 분석합니다.

비즈니스 모델

제휴 대학으로부터 연간 선납금을 수취하고, 고객에게는 데이터 기반 맞춤 추천과 포트폴리오 생성 기능에 대해 월정액 또는 추가 기능 이용료를 받는 구조입니다. 멘토링·컨설팅 연결 시 개인으로부터, 활동·공고 추천 시 기업으로부터 중개 수수료를 받는 수익 구조도 함께 설계했습니다.

1차 타깃은 건국대학교, 세종대학교, 한양대학교로, 각 학교 강점 학과에 맞춰 포트폴리오 추천을 커스터마이징하고, 이후 서울 소재 20개 대학, 전국 대학으로 단계적으로 확장하는 전략을 세웠습니다.
